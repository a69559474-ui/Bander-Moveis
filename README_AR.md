# Bander Moves — مشروع أندرويد أولي

تطبيق مكتبة أفلام ومسلسلات تجريبي بواجهة عربية داكنة، مع بحث وتصنيفات وصفحات تفاصيل وتشغيل فيديو وتنزيل روابط فيديو مباشرة يملك المستخدم حق استخدامها.

## الألوان
- الأحمر: اللون الأساسي للأزرار والعناوين.
- الأزرق: شريط الفيديو في الشعار.
- الأسود: خلفية التطبيق.

## البناء
هذا مشروع مصدر Android وليس APK جاهزًا. افتح مجلد `BanderMovesAndroid` في Android Studio، وانتظر مزامنة Gradle، ثم اختر Build > Build APK(s).

يمكن استخدام AndroidIDE على الهاتف، لكن نجاح البناء يعتمد على إصدار AndroidIDE وتهيئة Gradle المتاحة. لم يتم بناء APK أو اختباره في هذه الحزمة.

## المحتوى
العناصر المعروضة تجريبية. أضف فقط روابط فيديو تملك حق توزيعها أو روابط محتوى مرخص ومتاح قانونيًا. التنزيل الحالي يتعامل مع روابط ملفات فيديو مباشرة، وليس مع خدمات البث المحمية أو روابط صفحات الويب.


## تنبيه
هذه الحزمة لا تحتوي على APK جاهز. ملف gradlew المضاف محاولة توافق فقط إذا كانت أداة gradle متاحة في AndroidIDE. لم يتم اختبار البناء بعد.
